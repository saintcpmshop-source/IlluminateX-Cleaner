<h3 style="color: #38bdf8;">🌟 What is IlluminateMount?</h3>

**IlluminateMount** is a premium, lightweight standalone ISO mounter designed exclusively for CFW PlayStation 3 consoles. It replaces bulky file managers by offering a lightning-fast way to scan your USB or Internal HDD for `.iso` files and mount them directly to the XMB. 

<h3 style="color: #D4AF37;">⚡ Features</h3>
*   **🚀 Lightning Fast:** Instantly scans `/PS3ISO/` on USB and HDD.
*   **💾 Kernel Mounting:** Uses native Cobra syscalls for perfect compatibility.
*   **🛠️ Simple Interface:** Numbered list. Type the number to mount.
*   **🔒 Safe:** Auto-unmounts previous games to prevent crashes.

<h3 style="color: #38bdf8;">🛠️ How to Use</h3>
1. Place `.iso` files in a `PS3ISO` folder on your USB.
2. Launch IlluminateMount on your PS3.
3. Select the game number.
4. Exit the app and go to the **Game** column on the XMB to play!
